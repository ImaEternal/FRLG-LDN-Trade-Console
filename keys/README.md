# keys/

`prod.keys` goes here. **It is gitignored and must never be committed.**

These are your console's encryption keys. Dump them from a Switch you own with
[Lockpick_RCM](https://github.com/shchmue/Lockpick_RCM) — they are not
downloadable, and sites offering them are distributing circumvention keys.

The dashboard reads the four LDN needs: `aes_kek_generation_source`,
`aes_key_generation_source`, `master_key_00`, `master_key_12`.
